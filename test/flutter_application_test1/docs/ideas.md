# Идеи на потом

Сюда записываем то, что **не входит** в текущий этап. Агенты не берут эти идеи в работу без отдельной задачи.

- Профиль-тег: украшение с NFC-чипом, которое показывает профили в соцсетях.
- NFC-брелок или чип, который легко прикрепить к готовым украшениям (вместо полноценного украшения).
- Отслеживание продуктов.
- Напоминания о дедлайнах.
