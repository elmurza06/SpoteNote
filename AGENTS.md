# SpotNote — контекст для всех ИИ-агентов

Этот файл читает любой агент (Claude, Gemini, ChatGPT, Codex, Cursor) перед работой.
Здесь только главное. Подробности лежат в `docs/` (ссылки ниже).

## Что это за проект
SpotNote — мобильное приложение на Flutter для Android. Пользователь создаёт списки
(To-Do, обычный список, Wi-Fi, «поделиться»). У каждого списка есть свой адрес вида
`spot://...`. На NFC-метку записывается **только адрес**, а сам список хранится
в телефоне. Если приложить телефон к метке, откроется нужный список.

Целевой пользователь: студенты технических специальностей 18–25 лет в Бишкеке,
которые забывают рутинные дела. Это учебный проект: мидтерм, Demo Day,
оценка по 7 критериям на 100 баллов.

## Технические правила
- Состояние: один `AppState extends ChangeNotifier` + `ListenableBuilder`. Без Riverpod/Bloc, пока об этом не договорились.
- Сохранение: `shared_preferences` + JSON (`toJson`/`fromJson` в моделях).
- UI: тёмная тема Graphite & Stone. Цвета берутся только из `AppColors`, тени не используются, у карточек рамка 1px, диалоги делаются через `showModalBottomSheet`. Полная палитра есть в мастер-плане, раздел 3.
- Перед сдачей работы выполнить `flutter analyze` без ошибок.
- Не переписывать файлы, которые относятся к зоне ответственности другого агента (см. мастер-план, раздел 2).
- Пустые файлы-заглушки (`login_screen.dart`, `api_service.dart` и т.п.) — это места под будущий код, не удаляй их без спроса.

## Как работаем
1. Работа идёт этапами (Stage-Gate): к следующему этапу переходим только после проверки предыдущего.
2. В конце каждой задачи агент пишет отчёт по шаблону ниже и сохраняет его в
   `docs/progress/` (имя файла: `REPORT_<номер>_<агент>.md`).
3. Важные решения записываются в `docs/progress/decisions.md` (что решили и почему).

```
### REPORT: [Агент] — [Этап №, задача]
- Статус: Выполнено / Есть ошибки
- Изменённые файлы:
- Что сделано:
- Проверка: (результат flutter analyze / эмулятор)
- Вопросы:
```
